# Casino Roulette

カジノのルーレット（ヨーロピアン・0〜36）をブラウザで遊べる Web サイトです。

## 遊び方

1. チップ（10 / 50 / 100 / 500 / 1K）を選ぶ
2. テーブルのマスをクリックしてチップを置く（右クリックで外す）
3. 「SPIN！」ボタン（またはスペースキー）で回す
4. 玉が止まった数字で当たり・はずれが決まり、配当が残高に入る

## できること

- 数字・赤黒・奇数偶数・前半後半・ダズン・カラムへのベット
- 1つ戻す / 全部取り消し / 前回と同じ / 賭け金×2
- 直近15回の結果の履歴
- 残高と履歴はブラウザに保存（再読み込みしても続きから）
- チップがなくなったら補充ボタン

## 使った技術

- HTML / CSS / JavaScript（ライブラリなし）
- ルーレット盤は `<canvas>` で描画してアニメーション
- 結果は `crypto.getRandomValues` で決めています
